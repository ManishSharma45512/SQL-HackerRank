## 🟢 About the Repository

Welcome to the **SQL-HackerRank** repository! This repo serves as an organized archive of solutions to SQL problems ranging from **Basic Select** to **Advanced Joins**, **Aggregations**, and **Subqueries** on HackerRank. 

Every query is written with a focus on readability, optimization, and adherence to standard SQL syntax.
